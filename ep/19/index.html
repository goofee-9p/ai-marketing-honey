EP.19 · 화면 이름

'그 뜨는 창' 하면,
AI한테 두 번 말해요

AI로 만든 이벤트 페이지에 쿠폰 창 · 장바구니 알림 · 설명 말풍선 · 용량 목록이 다 떠요. 여기서 "그 뜨는 창 좀 작게 해 줘"라고 세 번 시켰더니 세 번 다 쿠폰 창을 줄였어요. 내가 말한 게 장바구니 알림이었다면 엉뚱한 데가 바뀐 거예요. "장바구니 토스트만 작게"처럼 이름으로 시키면 딱 그것만 바뀌었어요. AI한테는, 아는 만큼 시킬 수 있어요.

01뜨는 게 이렇게 많아요

Claude에게 화면 이름은 빼고 생김새로만 설명해서 만든 허니 뷰티(예시) 이벤트 페이지예요. 왼쪽은 들어오자마자 뜨는 쿠폰 창, 오른쪽은 용량 목록을 펼치고 장바구니에 담은 화면이에요.

02화면 이름 카드 14장

이벤트 페이지 · 랜딩페이지 · 배너 툴을 AI로 만들고 고칠 때 자주 나오는 이름이에요. 꿀색 테두리 두 장이 이번 영상에서 쓴 이름이에요. 예문의 문구·숫자만 내 것으로 바꾸세요.

모달Modal · 팝업

화면 가운데 크게 뜨고 뒤가 어두워지는 창. 닫기 전엔 뒤를 못 눌러요.

들어오자마자 뜨는 쿠폰 모달, 폭을 260px로 줄이고 닫기 버튼을 더 크게 해 줘.
토스트Toast

잠깐 떴다가 저절로 사라지는 작은 알림. "장바구니에 담았어요" 같은 거예요.

장바구니 토스트만 작게 하고, 2초 뒤에 사라지게 해 줘.
드롭다운Dropdown · 셀렉트

누르면 아래로 펼쳐지는 선택 목록. 용량·색상·수량 고를 때 써요.

용량 드롭다운에 '3개 세트'를 추가하고 기본값을 50ml로 해 줘.
아코디언Accordion

제목을 누르면 내용이 펼쳐지고 다시 누르면 접히는 칸. 자주 묻는 질문에 많이 써요.

FAQ 아코디언은 한 번에 하나만 열리게 하고, 첫 질문은 펼쳐 둬.
탭Tab

같은 자리에서 내용을 바꿔 보는 버튼 줄. 상세 정보 · 리뷰 · 배송 안내 같은 거예요.

상세 정보·리뷰·배송 안내 탭에서, 들어오면 리뷰 탭이 먼저 열려 있게 해 줘.
캐러셀Carousel · 슬라이더

옆으로 넘겨 보는 사진 묶음. 아래 점이 몇 번째인지 알려 줘요.

제품 사진 캐러셀이 3초마다 저절로 넘어가게 하고, 점을 누르면 그 사진으로 가게 해 줘.
툴팁Tooltip

ⓘ에 마우스를 올리거나 누르면 뜨는 작은 설명 말풍선.

'무료 배송' 툴팁 문구를 '3만 원 이상 무료 · 제주 3,000원 추가'로 바꿔 줘.
배지Badge · 라벨

이름 옆에 붙는 작은 표시. BEST · NEW · 30% 같은 거예요.

제품 이름 옆 BEST 배지를 빨간색 'NEW' 배지로 바꿔 줘.
토글Toggle · 스위치

눌러서 켜고 끄는 스위치. 수신 동의 · 알림 받기에 써요.

회원가입 아래에 '광고성 정보 수신 동의' 토글을 넣고, 기본은 꺼 둬.
플로팅 버튼Floating button

스크롤해도 화면 구석에 늘 떠 있는 버튼. 문의 · 맨 위로 같은 거예요.

오른쪽 아래 '문의' 플로팅 버튼을 '카톡 상담'으로 바꾸고, 장바구니 버튼을 가리지 않게 조금 위로 올려 줘.
스티키 헤더Sticky header

스크롤해도 맨 위에 붙어서 따라오는 바(상단 고정 바).

스티키 헤더 오른쪽에 '쿠폰 받기' 버튼을 넣고, 누르면 쿠폰 모달이 뜨게 해 줘.
히어로Hero · 메인 배너

페이지 맨 위, 가장 크게 보이는 첫 화면.

히어로 문구를 '가을 한정 최대 30%'로 바꾸고, 기간 글자를 더 크게 해 줘.
바텀 시트Bottom sheet

화면 아래에서 올라오는 판. 옵션 고르기 · 공유하기에 많이 써요.

'구매하기'를 누르면 용량을 고르는 바텀 시트가 아래에서 올라오게 해 줘.
푸터Footer

페이지 맨 아래 회사 정보 · 약관 · 고객센터 칸.

푸터에 인스타 링크와 고객센터 운영 시간 줄을 추가해 줘.

03이렇게 시키세요

이름으로 시키는 틀
[어느 화면]의 [화면 이름]만 [어떻게] 바꿔 줘. 다른 건 그대로 둬.

💡 예: "이벤트 페이지의 장바구니 토스트만 작게 해 줘. 다른 건 그대로 둬." 같은 이름이 여러 군데 쓰이면 앞에 어디 것인지 붙여요(쿠폰 모달 · 장바구니 토스트). 이번 시험에서 토스트는 장바구니 · 쿠폰 받기 · 문의가 같이 쓰는 칸이었는데, "장바구니 토스트만"이라고 하니 장바구니 알림만 작아졌어요.

이름을 모를 때 먼저 물어보기
이 페이지에 있는 화면 요소 이름을 목록으로 알려 줘(모달, 토스트처럼). 각각 화면 어디에 있는지도 한 줄씩.
바꿀 줄만 알려 줄 때

HTML 파일을 붙여서 고쳐 달라고 하면, 이번 시험 9번 모두 고칠 CSS·JS 줄만 알려 줬어요(파일을 새로 만들어 주진 않았어요). 직접 붙이기 어려우면 "고친 파일 전체로 줘"라고 한 번 더 말하세요.

한 줄 요약

AI는 '그 뜨는 창'을 세 번 다 쿠폰 창으로 알아듣고, 묻기 전에 먼저 고쳤어요. 줄이고 싶은 게 쿠폰 창이었다면 맞힌 거지만, 장바구니 알림이었다면 세 번 다 엉뚱한 데를 고친 거예요. 이름으로 시킨 6번은 모두 그것만 바뀌었어요.

05어떻게 시험했나

  • 도구: claude.ai(Claude · Opus 5.5 · 중간), 2026-10-26.
  • 데모 페이지: 화면 이름은 빼고 생김새로만 부탁해서 만든 HTML 한 장(2분 30초).
  • 부탁마다 시크릿 대화를 새로 열고 같은 HTML 파일을 붙여 한 줄만 보냈어요. 3번씩, 모두 9번. 돌아온 코드가 어느 요소를 바꾸는지로 셌어요.
  • 원하는 곳은 처음에 '쿠폰 창'으로 정하고 돌렸어요. 결과를 본 뒤 "장바구니 알림이었다면?"을 확인하려고 '장바구니 토스트' 부탁 3번을 더 돌렸어요.
  • 부탁마다 3번뿐이고 모델도 하나예요. 다른 AI · 다른 페이지에서는 결과가 달라질 수 있어요.
  • '그 뜨는 창'이 늘 틀린다는 뜻은 아니에요. 이번 페이지에서는 AI가 매번 쿠폰 창을 골랐고, 다른 걸 말한 사람은 한 번 더 말해야 했다는 뜻이에요.
  • 시험한 페이지는 '허니 뷰티'라는 가상 브랜드 예시예요.
