EP.15 · 웹사이트 배포

AI로 만든 웹사이트,
남들은 못 열어요

AI로 만든 웹사이트가 내 컴퓨터에서만 돌아가고 있다면, 다른 사람은 볼 방법이 없어요. 인터넷에 올려서 링크로 열리게 하는 것, 이걸 배포라고 해요. 그때 쓰는 서비스가 Vercel이에요.

배포가 뭔지AI에 줄 요청문보낼 링크 찾는 곳무료 조건

01왜 남들은 못 열까요

AI가 만들어 준 웹사이트를 내 컴퓨터에서 열면 주소가 localhost:3000 같은 모양이에요. 'localhost'는 지금 이 컴퓨터라는 뜻이라, 다른 사람이 같은 주소를 열면 그 사람 컴퓨터(폰)를 찾다가 "사이트에 연결할 수 없음"이 떠요.

02Vercel로 배포하기 — AI에 그대로 붙여 넣는 요청문

웹사이트를 만든 대화(Claude · ChatGPT · Cursor 등)에 이어서 붙여 넣어요. Vercel 가입·로그인과 권한 승인은 직접 눌러야 해요.

Vercel로 배포하고 링크 받기
이 웹사이트를 다른 사람도 링크로 열 수 있게 Vercel에 배포해 줘.
1. 내가 직접 해야 하는 일(Vercel 가입·로그인, 승인 버튼)을 순서대로 알려 줘.
2. 배포가 끝나면 다른 사람에게 보낼 '프로덕션 도메인'(짧은 주소, 예: 이름.vercel.app)을 알려 줘. 배포마다 생기는 긴 주소 말고.
3. 나중에 내용을 고쳐서 다시 올리는 방법도 알려 줘. 같은 짧은 주소에 반영되게.
4. API 키 같은 비밀 값이 코드에 있으면 빼고 Vercel 환경 변수로 옮겨 줘.
코드는 몰라도 따라 할 수 있게 한 단계씩 설명해 줘.

03보낼 링크는 이거예요

Vercel 대시보드 → 내 프로젝트 → Overview → Domains 칸의 짧은 주소(예: honey-banner.vercel.app)를 보내요. 고쳐서 다시 올려도 이 주소는 그대로고, 열면 가장 최근 버전이 보여요.

  • 위쪽 Deployment 칸의 긴 주소(예: 이름-7k2d-….vercel.app)는 기본 설정에서 Vercel 로그인한 사람만 열려요. 다른 사람에겐 Domains 칸의 짧은 주소를 보내요(2026-10-24 직접 확인).

04써 보기 전에 꼭

  • 무료(Hobby) 플랜은 개인·비상업 용도만이에요. 회사 업무에 쓰는 웹사이트면 Pro 플랜 대상이에요.
  • 짧은 주소는 아는 사람 누구나 열 수 있어요. 고객 정보·내부 자료는 올리지 말고, 우리 팀만 보게 하려면 로그인을 붙여요(EP.16 참고).
  • API 키·비밀번호를 코드에 그대로 두면 링크를 연 사람이 볼 수 있어요. 환경 변수로 옮겨요.

05출처
