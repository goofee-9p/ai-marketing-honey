EP.24 · 깃허브

노트북 덮으면,
AI도 멈춰요

Claude Code · Codex처럼 내 노트북에서 파일을 만지며 일하는 AI는 노트북이 잠들면 같이 멈춰요. 작업 폴더를 GitHub에 올려 두면, Claude가 노트북 대신 인터넷(클라우드)에서 그 폴더로 일해요. 노트북을 덮어도 계속 돌고, 폰으로도 시킬 수 있어요.

처음 올리는 순서요청문폰으로 시키는 법알아 둘 점

01왜 멈출까

내 컴퓨터에서 도는 AI는 그 노트북의 파일과 프로그램으로 일해요. 덮어서 잠자기에 들어가면 AI도 같이 멈추고, 작업 폴더도 그 노트북 안에만 있어요. 그래서 회사 컴퓨터에서 이어서 하려 해도 폴더가 없어요.

ChatGPT · Claude 채팅은 해당 없어요

채팅 앱은 원래 인터넷에서 돌아서, 노트북을 덮어도 답은 계속 만들어져요. 이 노트는 내 컴퓨터 폴더로 일하는 AI 이야기예요.

02처음 올리는 순서 그대로

  1. GitHub 가입 — github.com에서 무료 계정을 만들어요.
  2. 저장소는 비공개(Private)로 — 공개로 두면 누구나 폴더 안을 볼 수 있어요. 아래 요청문에 '비공개'를 꼭 넣어요.
  3. AI에게 올려 달라고 하기 — 내 컴퓨터의 Claude Code · Codex에 아래 요청문을 붙여 넣어요. 처음 한 번은 GitHub 로그인 창이 떠요.
  4. Claude에 GitHub 연결 — claude.ai/code(또는 Claude 앱의 Code 탭)에서 GitHub를 연결해요. 비공개 저장소는 Claude GitHub 앱을 그 저장소에 설치해야 보여요.
  5. 저장소 고르고 할 일 적기 — 이제 노트북을 덮어도 돼요.

03요청문

처음 올릴 때 — 내 컴퓨터의 Claude Code · Codex에
이 작업 폴더를 내 GitHub에 비공개(Private) 저장소로 올려 줘.
- 저장소 이름: [원하는 이름]
- 비밀번호 · API 키가 든 파일(.env 같은 것)은 올리지 말고 .gitignore에 넣어 줘
- 다 올리면 저장소 주소랑, 올라간 파일 목록을 알려 줘
GitHub를 처음 쓰면 AI가 'gh 로그인'이나 'git 설치'부터 하자고 할 수 있어요. 화면에 뜨는 대로 로그인만 해 주면 돼요.
다른 컴퓨터에서 이어서 할 때
내 GitHub의 [저장소 이름] 저장소를 이 컴퓨터로 내려받아 줘.
앞으로 작업 시작할 땐 최신으로 받고, 끝나면 GitHub에 올려 줘.
클라우드에서 끝난 작업을 내 컴퓨터로 가져올 때
GitHub에 Claude가 올린 작업(브랜치)을 이 컴퓨터로 받아서, 무엇이 바뀌었는지 알려 줘.

04폰으로 시키는 법

  1. Claude 앱 → Code 탭(브라우저는 claude.ai/code).
  2. 올려 둔 저장소를 고르고, 할 일을 평소처럼 적어요. 예: "어제 광고 성과 CSV로 보고서 한 장 만들어 줘".
  3. Claude는 인터넷 속 컴퓨터에서 저장소를 받아 일하고, 결과를 GitHub에 새 갈래(브랜치)로 올려요. 노트북을 닫아도 계속 돌고, 진행 상황은 폰 · 노트북 어디서든 확인해요.

05알아 둘 점

  • 저장소는 꼭 비공개로. 공개 저장소는 누구나 보고 가져갈 수 있어요. 회사 자료 · 고객 데이터는 비공개여도 회사 규정을 먼저 확인해요.
  • 비밀번호 · API 키 파일은 올리지 않기. 요청문에 넣은 '.gitignore' 한 줄이 그 역할이에요.
  • 요금제: 클라우드에서 돌리기는 Claude Pro · Max · Team 등에서 돼요(Enterprise는 좌석 조건). 사용량은 요금제 한도에서 같이 빠지고, 클라우드 컴퓨터 요금은 따로 없어요.
  • 클라우드 컴퓨터는 내 노트북이 아니에요. 내 컴퓨터에 로그인된 사이트 · 프로그램은 못 써요. GitHub에 올라간 파일로만 일해요.
  • 한동안 아무것도 안 하면 클라우드 세션이 쉬어요. 다시 열면 대화는 그대로 이어져요.

06출처

  • Claude Code 공식 문서 'Use Claude Code in the cloud'(code.claude.com/docs/en/claude-code-on-the-web) — 2026-11-03 확인.
  • 영상 속 GitHub 화면은 이 채널의 실제 작업 저장소(비공개)예요. 폰 화면은 예시로 그린 그림이에요.
  • 썸네일 사진은 AI로 만들었어요.
