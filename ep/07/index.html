알트탭 누르는 마케터
없게 해주세요

엑셀에서 한 열을 복사하고, Ctrl+V만 연타하면 한 칸씩 순서대로 붙여넣어지는 작은 툴이에요. 구글 PMax 광고 제목 15개를 넣다가 귀찮아서, Claude랑 직접 만들었어요.

툴 파일설치 5분만드는 프롬프트

01이렇게 써요

  1. 엑셀에서 한 열 복사넣을 문구가 들어 있는 열(여러 줄)을 선택하고 Ctrl+C. 노션 목록도 돼요.
  2. Ctrl + Alt + V연속 붙여넣기가 켜지고, 화면 오른쪽 위에 '연속 붙여넣기 0/15' 창이 떠요.
  3. Ctrl + V 연타칸을 클릭(또는 Tab)하고 Ctrl+V를 누를 때마다 다음 줄이 들어가요. 창의 숫자가 올라가요.
  4. 다 넣으면 자동으로 꺼져요원래 복사해 둔 내용으로 돌아가요. 중간에 끄려면 Ctrl+Alt+V를 한 번 더.

실제 구글 광고 계정에서 캠페인 초안으로 시연했어요(게시 안 함). 문구는 가상 브랜드 예시예요.

02설치하기

  1. 파일 받기paste-queue.zip을 받아 압축을 풀어요.
  2. Node.js 설치nodejs.org에서 LTS 버전을 설치해요.
  3. 실행압축 푼 폴더에서 터미널(윈도우는 PowerShell)을 열고 npm install → npm start
맥에서 쓸 때

켜는 키는 Control+Option+V, 붙여넣기는 평소처럼 ⌘V예요. 처음 한 번 '손쉬운 사용' 권한을 켜 주세요(시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용).

03이런 데서도 써요

상세페이지 옵션명

색상·용량 옵션을 엑셀에 정리해 두고, 옵션 칸마다 Ctrl+V만 눌러요.

키워드 · 광고 문구 등록

한 칸에 하나씩 넣어야 하는 입력창이면 어디든 돼요.

04Claude로 직접 만들기

코딩을 몰라도 돼요. 아래처럼 하고 싶은 걸 말로 설명하면 Claude가 만들어 줘요. 저도 이렇게 시작했어요.

① 툴 만들어 달라고 하기
엑셀에서 한 열을 복사한 다음, 붙여넣기를 누를 때마다
다음 줄이 순서대로 붙여넣어지는 작은 프로그램을 만들어 줘.
- Ctrl+Alt+V로 켜고 끄기, 꺼져 있을 땐 평소 붙여넣기 그대로
- 화면 구석에 '지금 몇 번째 / 전체 몇 개'와 다음 줄 미리보기
- 다 넣으면 자동으로 꺼지고, 원래 복사해 둔 내용으로 되돌리기
- 윈도우에서 쓸 거야. 설치하고 실행하는 방법도 쉽게 알려 줘.
② 내 업무에 맞게 고치기
방금 만든 툴을 이렇게 바꿔 줘.
- 엑셀에서 여러 열을 복사하면, 왼쪽부터 한 칸씩 가로로 넣기
- 붙여넣은 다음 Tab을 자동으로 눌러서 다음 칸으로 넘어가기

💡 처음부터 완벽하게 만들려고 하지 마세요. 써 보고 불편한 점을 한 줄씩 말하면 돼요.

05써 보기 전에 꼭

  • 회사 컴퓨터라면 프로그램을 설치하기 전에 보안 정책을 확인하세요.
  • 붙여넣은 내용은 꼭 한 번 확인하세요. 칸을 건너뛰면 순서가 밀릴 수 있어요.
  • 켜 둔 동안에는 Ctrl+V가 '다음 줄'로 바뀌어요. 다 쓰면 Ctrl+Alt+V로 꺼 두세요.
