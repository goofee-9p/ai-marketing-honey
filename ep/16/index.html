EP.16 · 팀이 같이 쓰는 툴

내가 만든 툴도,
피그마처럼 같이 쓰기

AI로 만든 툴은 링크로 같이 열어도, 고친 내용이 각자 컴퓨터에만 남아요. 팀원이 바꾼 문구를 메신저로 다시 물어보고 있다면, 툴에 '팀 공용 창고'를 붙이면 돼요. 그게 Supabase예요.

AI에 줄 요청문무료 한도보안 체크

01AI에 그대로 붙여 넣는 요청문

툴을 만든 대화(Claude · ChatGPT · Cursor 등)에 이어서 붙여 넣어요. Supabase 가입과 새 프로젝트 만들기, 키 붙여 넣기는 직접 해야 해요. AI가 어디서 무엇을 복사하라고 알려 줘요.

팀 저장 · 로그인 · 실시간 붙이기
이 툴을 팀원들과 같이 쓰게 바꿔 줘. 저장소는 Supabase를 쓸 거야.
1. 지금 화면에서 고치는 내용(예: 헤드라인, 버튼 문구, 사이즈)을 Supabase 표에 저장해 줘.
2. 이메일로 로그인한 사람만 툴을 열 수 있게 해 줘. 로그인 안 한 사람은 로그인 화면만 보여.
3. 접근 규칙(RLS)을 켜서, 우리 팀 사람만 읽고 쓸 수 있게 해 줘.
4. 다른 사람이 고치면 새로고침 없이 내 화면에도 바로 보이게 실시간 반영(Realtime)도 켜 줘.
5. 내가 Supabase에서 직접 해야 하는 일(프로젝트 만들기, 키 복사 위치, 표 만들기 SQL)을 순서대로 알려 줘.
코드는 몰라도 따라 할 수 있게 한 단계씩 설명해 줘.

💡 팀원이 링크로 열게 하려면 툴을 인터넷에 올려 주소가 있어야 해요(예: Vercel). 이미 올렸다면 "다시 올려 줘"까지 같이 요청하세요.

02한 장으로 보는 구조

툴 = 화면, Supabase = 팀 공용 창고

누가 고쳐도 창고(표)에 저장되고, 모두의 화면이 창고에서 같은 값을 읽어 와요. 로그인은 창고의 문이에요. 문을 연 우리 팀만 들어와요.

03써 보기 전에 꼭

  • 무료(Free) 한도: 프로젝트 2개 · 데이터베이스 500MB. 1주일 동안 안 쓰면 일시정지돼요. 데이터는 남지만, 대시보드에서 다시 켜기 전까지 툴이 안 열려요.
  • RLS(접근 규칙)는 꼭 켜요. 꺼져 있으면 주소와 키를 아는 사람이 표를 읽을 수 있어요.
  • 고객 개인정보, 광고 계정 비밀번호 같은 민감한 정보는 넣지 않아요. 회사 보안 규정이 있다면 먼저 확인하세요.
  • 실시간 반영은 기본으로 꺼져 있어요. 켜지 않으면 새로고침해야 보여요.
