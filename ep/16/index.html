EP.16 · 팀이 같이 쓰는 툴

내가 만든 툴도,
피그마처럼 같이 쓰기

팀원이 고친 문구가 내 화면엔 없어서 메신저로 다시 묻고 있다면, 이유는 저장 위치예요. 처음 만든 AI 툴은 보통 고친 내용을 각자 브라우저에만 저장해요. 툴을 만든 AI한테 저장 위치를 Supabase(팀 공용 창고)로 바꿔 달라고 하면, 누가 고쳐도 한곳에 저장되고 모두의 화면에 같은 문구가 떠요.

AI에 줄 요청문연결 단계더 하기

01AI에 그대로 붙여 넣는 요청문

툴을 만든 그 대화(Claude · ChatGPT · Cursor 등)에 이어서 붙여 넣어요.

저장 위치를 Supabase로
이 툴은 지금 고친 내용이 내 브라우저에만 저장돼서 팀원 화면에는 안 보여.
저장 위치를 Supabase로 바꿔 줘. 지금 화면에서 고치는 내용(예: 헤드라인, 버튼 문구, 사이즈)을 Supabase 표에 저장하고, 툴을 열면 그 표에서 불러오게 해 줘.
내가 Supabase에서 직접 해야 하는 일(프로젝트 만들기, 키 복사 위치, 표 만드는 SQL)을 순서대로 알려 줘.
다른 사람이 고치면 새로고침 없이 내 화면에도 바로 보이게, 실시간 반영(Realtime)도 켜 줘.
코드는 몰라도 따라 할 수 있게 한 단계씩 설명해 줘.

💡 팀원이 링크로 열게 하려면 툴이 인터넷 주소로 올라가 있어야 해요(EP.15 참고). 이미 올렸다면 "바꾼 다음 다시 올려 줘"까지 같이 요청하세요.

02연결 단계 (직접 하는 부분)

  1. supabase.com에 가입하고 New project를 만들어요(무료 플랜).
  2. AI가 준 표 만드는 SQL을 프로젝트의 SQL Editor에 붙여 넣고 실행해요.
  3. 프로젝트 설정의 API 화면에서 Project URL과 공개용 키(anon/publishable)를 복사해 AI한테 줘요. service_role 키는 주지 마세요.
  4. AI가 고쳐 준 툴을 다시 올리고, 내가 문구를 고친 뒤 팀원 화면에도 같은 문구가 뜨는지 확인해요.

03더 하기 (필요할 때만)

우리 팀만 들어오게 — 로그인 + 접근 규칙(RLS)

AI한테 "이메일로 로그인한 사람만 열 수 있게 하고, 접근 규칙(RLS)을 켜서 우리 팀만 읽고 쓰게 해 줘"라고 덧붙여요. RLS가 꺼져 있으면 주소와 키를 아는 사람이 표를 읽을 수 있어요.

바로 안 바뀐다면 — 실시간 반영(Realtime) 확인

요청문 마지막 줄이 실시간 반영이에요. 기본은 꺼져 있어서, 빠지면 새로고침해야 보여요. 안 바뀌면 AI한테 "Realtime이 켜져 있는지 확인해 줘"라고 물어보세요.

  • 무료(Free) 한도: 프로젝트 2개 · 데이터베이스 500MB. 1주일 동안 안 쓰면 일시정지돼요. 데이터는 남지만, 대시보드에서 다시 켜기 전까지 툴이 안 열려요.
  • 고객 개인정보, 광고 계정 비밀번호 같은 민감한 정보는 넣지 않아요. 회사 보안 규정이 있다면 먼저 확인하세요.
