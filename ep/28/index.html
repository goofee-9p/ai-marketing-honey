02폰으로 시키는 순서

  1. 작업 폴더를 GitHub 비공개 저장소에 올려요. GitHub 개인 무료 계정도 비공개 저장소를 쓸 수 있어요. 처음 올리는 순서는 EP.24 노트에 있어요.
  2. 폰 Claude 앱 › Code 탭을 열어요. 처음 한 번은 GitHub 연결이 필요해요.
  3. 저장소와 브랜치를 고르고, 할 일을 적어 보내요. 그다음은 앱을 닫아도 일이 이어져요. 앱에서 진행 상황을 보고 추가로 지시할 수 있어요.
  4. 결과는 저장소의 브랜치로 올라와요. 앱이나 브라우저에서 바뀐 내용을 확인해요.

03예시 요청문

파일로 하는 일 하나를 시키는 예시예요. 대괄호만 내 걸로 바꿔요.

복사해서 Code 탭에 붙여 넣기
이 저장소의 [데이터 폴더]에 있는 광고 성과 CSV 파일들을 합쳐서 주간 리포트를 만들어 줘.
- 숫자는 파일에서 계산해서 쓰고, 지어내지 마.
- 맨 위에 이번 주 결론 1~2문장, 그 아래 매체별 표(광고비 · 구매 · 매출 · ROAS).
- 결과는 [리포트 폴더]/주간리포트.html로 저장하고 브랜치로 올려 줘.
- 원본 CSV는 고치지 마.
처음에는 가상 데이터나 공개해도 되는 샘플로 시험해 보세요. 숫자는 꼭 파일에서 계산하게 시켜요.

04꼭 알아 둘 조건

  • '추가 0원'은 지금 쓰는 유료 요금제 그대로라는 뜻이에요. 클라우드 세션은 Pro · Max · Ultra · Team에서 돼요(Enterprise는 좌석 조건). 유료 요금제를 안 쓰고 있다면 요금제 값은 들어요.
  • 사용량은 요금제 한도에서 같이 빠져요. 클라우드 컴퓨터 요금은 따로 없지만 Claude · Claude Code를 쓴 양과 합쳐져요. 여러 작업을 동시에 돌리면 그만큼 빨리 차요.
  • 24시간 켜져 있는 컴퓨터는 아니에요. 시킨 일을 하는 동안 돌고, 활동이 없으면 몇 분 뒤 멈춰요(파일은 저장돼요). 오래 지나 다시 열면 대화는 복원되지만 돌던 작업은 다시 시켜야 해요.
  • 명령 하나에 시간 제한이 있어요. 기본값으로 앞에서 최대 10분, 뒤로 넘겨서 30분 더 돌아요. 설정으로 늘릴 수 있어요.
  • 기본 네트워크는 허용 목록에 있는 곳만 돼요. 패키지 저장소 · GitHub 같은 곳이에요. 다른 사이트에 접속해야 하면 환경 설정에서 넓혀요.
  • 저장소는 꼭 비공개로. 비밀번호 · API 키 파일은 올리지 않아요. 회사 자료는 회사 규정을 먼저 확인해요.
  • 켜 둔 컴퓨터가 잠들면 원격으로 잇는 세션은 멈췄다가, 컴퓨터가 다시 온라인이 되면 이어져요.

ChatGPT · Claude 채팅 앱은 원래 인터넷에서 돌아서 이 표와 상관없어요.
