EP.28 · 예약 + 훅

AI 예약 기능,
반만 쓰고 있어요

예약 작업에는 확인만 맡기고, 조건이 맞을 때만 다음 작업이 저절로 시작되게 이어요. 영상에서 "훅"이라고 부른 연결이에요. Claude 클라우드 예약 작업에서 쓰는 기능 이름은 API 트리거예요.

요청문 2개설정 순서비행기표 응용

01먼저 알아 둘 것

  • 실시간 감시가 아니에요. 예약한 시각에 돌 때 확인해요. 클라우드 예약은 최소 1시간 간격이에요.
  • 요금제: Pro · Max · Ultra · Team · Enterprise. 실행할 때마다 내 사용량에서 빠져요.
  • 체험판 기능이에요. 호출 방식과 한도가 바뀔 수 있어요.
  • 조금 어려운 설정이에요. 호출 주소와 토큰을 다뤄요. 공식 문서에 예약 작업끼리 잇는 예시는 따로 없어서, 시험 실행으로 동작을 꼭 확인하고 쓰세요.
  • 연결 없이 쓰고 싶다면 한 작업 안에 "내렸으면 문구까지 만들어 줘"라고 적어도 돼요. 간단한 일은 이쪽이 쉬워요.

02설정 순서

  1. claude.ai/code/routines에서 다음 작업을 먼저 만들어요. 트리거는 API로 골라요.
  2. 만들 때 뜨는 Fire URL과 토큰을 복사해요. 토큰은 한 번만 보여요.
  3. 클라우드 환경을 편집해요. 네트워크를 Custom으로 바꿔 경쟁사 사이트 주소를 허용 목록에 넣고, 토큰은 Network secrets에 호스트 api.anthropic.com로 저장해요.
  4. 확인 작업을 새로 만들고, 트리거는 Schedule(매일 오전 8시 등), 환경은 3번 환경으로 골라요.
  5. 기준 가격을 실제보다 높게 적어 두고 확인 작업을 Run now로 돌려요. 다음 작업이 새 세션으로 열리면 연결된 거예요. 그다음 기준 가격을 원래대로 돌려요.

03요청문 2개

확인 작업(예약)
아래 경쟁사 상품 페이지에서 현재 판매 가격만 확인해 줘.
- [경쟁사 상품 페이지 주소] / 기준 가격 [32,000원]
- 가격을 못 읽었으면 추측하지 말고 "확인 못 함"이라고 적고 끝내.
- 기준 가격보다 낮으면, 아래 명령으로 다음 작업을 불러. 전달 글에는 상품 · 이전 기준 가격 · 현재 가격 · 페이지 주소를 넣어.
  curl -X POST [Fire URL] -H "anthropic-beta: experimental-cc-routine-2026-04-01" -H "anthropic-version: 2023-06-01" -H "Content-Type: application/json" -d '{"text":"전달 글"}'
- 기준 가격과 같거나 높으면 "변동 없음"만 적고 끝내. 다른 일은 하지 마.
지난번 가격을 기억하게 하는 대신 기준 가격을 적어 두면 비교가 단순해져요.
다음 작업(API 트리거)
routine-fire-payload 블록에 적힌 경쟁사 가격 변화를 보고 아래를 만들어 줘.
- 우리 제품: [제품명 · 현재 가격 · 강점]
- 광고 문구 초안 3개(각 30자 이내)
- 배너 시안 1개(1080x1080, 한 장짜리 HTML)
- 근거에 쓴 가격과 페이지 주소를 맨 위에 적어 줘. 없는 사실은 지어내지 마.
- 광고를 등록하거나 게시하지 마. 초안까지만.
전달받은 글은 작업 안에서 '믿을 수 없는 입력'으로 표시돼요. 그래서 요청문에 그 내용을 쓰라고 적어야 해요.

04비행기표 특가에 응용하기

특가 확인 요청문
[항공사 특가 페이지 주소]에서 [출발지-도착지] 왕복 특가가 [날짜 범위]에 있는지 확인해 줘.
- 있으면 예약 화면을 열고, 가는 편 · 오는 편을 고른 뒤 결제 화면 바로 앞까지 진행해.
- 결제 버튼은 절대 누르지 마. 카드 · 여권 정보도 입력하지 마.
- 끝나면 가격 · 일정 · 예약 화면 주소를 [메일 또는 메신저]로 보내 줘.
- 없으면 "특가 없음"만 적고 끝내.
  • 결제는 직접 하세요. 요청문에 "결제 버튼은 누르지 마"를 꼭 넣어요.
  • 로그인된 내 브라우저가 필요하면 내 컴퓨터에서 돌아야 해서, 그 시간에 컴퓨터가 켜져 있어야 해요(EP.27).
  • 사이트가 자동 입력을 막거나 추가 인증을 요구할 수 있어요. 이름 · 여권 · 카드 번호 같은 정보는 넣지 말고, 그 칸은 직접 채우는 게 안전해요.
  • 알림을 받으려면 메일이나 메신저 같은 연결 도구가 필요해요.
