02규칙 파일 틀

처음부터 길게 쓰지 마세요. 한 편 만들고 거슬린 것만 적으면 돼요. 채팅 앱이면 대화 시작할 때 이 파일을 첨부하세요.

복사해서 파일로 저장(괄호만 바꿔요)
# (채널 이름) 제작 규칙

## 대상
- 누가 보는지: (직무 · 연차)
- 그 사람이 겪는 문제 예시: (한 줄)

## 대본
- 길이: (30초 안쪽) · 문장마다 번호
- 첫 문장 2안: 손해를 먼저 / 결과를 먼저
- 첫 3초에 도구 이름 꺼내지 않기
- 숫자는 내가 준 값만 쓰기. 없으면 숫자 없이 쓰기

## 화면
- 자막: (위치 · 글자 크기 · 한 줄 글자 수)
- 그림이나 캡처 위에 글자 · 칩 얹지 않기
- 썸네일: 글자 자리는 고정, 그림만 매번 새로

## 목소리
- 목소리 (이름) · 모델 (이름) · 안정성 (숫자) · 유사성 (숫자)
- 영어 · 숫자는 원고에만 읽는 대로 적기

## 지적 기록 (날짜 + 그때 한 말)
- (날짜) "(거슬렸던 말)" → (앞으로 지킬 규칙)

03단계별 요청문 — 처음엔 어디까지

다 하실 필요 없어요. 편집은 맨 나중에 맡겨도 돼요.

1단계 · 대본만 (채팅 앱이면 충분해요)
복사해서 붙이기
첨부한 규칙 파일을 먼저 읽어 줘.
(대상)이 실무에서 겪는 문제 "(문제 한 문장)"을 푸는 릴스 대본을 써 줘.
문장마다 번호를 붙이고, 1번 문장은 2안으로 줘(손해를 먼저 / 결과를 먼저).
숫자는 내가 준 것만 써. 없으면 숫자 없이 써.
2단계 · 목소리

설정 숫자를 고정하고 같은 값으로 뽑아요. 우리는 Han - Conversational · Eleven v4 · 안정성 53 · 유사성 75 · 한국어예요. 글자 수만큼 크레딧이 빠져요.

3단계 · 썸네일 그림

글자 자리는 내 템플릿에 두고 그림만 맡겨요. 이미지 AI는 한글을 잘 깨뜨려요.

그림 요청문 틀
(문제가 보이는 장면)을 사진처럼 그려 줘. 세로 3:4.
글자 · 로고는 넣지 마. 아래쪽 1/3은 제목이 들어가게 비워 줘.
후보 2장을 서로 다른 장면으로 줘.
4단계 · 영상 편집 (Claude Code 같은 코딩 에이전트)

처음 세팅은 오래 걸려요. 대신 틀을 만들면 다음 편부터 장면만 바꿔요.

검사 넣는 요청문
렌더 전에 화면 요소 위치를 기록해서, 칩이나 글자가 그림 · 캡처 위에 얹히면 실패로 멈추는 검사를 넣어 줘.
실패하면 어느 장면 몇 초인지 출력하고 영상을 만들지 마.
일부러 칩을 얹어서 검사가 실제로 잡는지도 확인해 줘.
